# Curvature-Bounded Enclosures of Simple Polygons

- `docs/`: the website (GitHub Pages): `index.html`, `Curvature_driven_evolution_short.pdf`, `Curvature_driven_evolution_long.pdf`, `media/` (simulation GIFs)
- `ce_streamlit_app.py` + `polygon_simulation.py` + `run_experiments.py` + `ce_canvas/` + `ce_slider/`: the interactive app (Streamlit)

Run the app locally:

    pip install -r requirements.txt
    streamlit run ce_streamlit_app.py
